# Release Notes

Release notes are published with GitHub releases.

CLI release tags use SemVer:

```text
v1.1.0
v1.1.1
v1.2.0
```

Documentation-only release tags use date-based tags:

```text
docs-v2026.05.18
docs-v2026.05.18.1
```

Do not use CLI release tags for documentation-only changes.
